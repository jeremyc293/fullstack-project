# PlaylistHub

PlaylistHub is a full-stack MERN application that allows users to create and manage music playlists, search for songs, listen to 30-second previews, and save songs to their own playlists.

## Features

- User registration
- User login
- JWT authentication
- Create playlists
- Edit playlists
- Delete playlists
- Search for songs and artists
- Listen to 30-second song previews
- Add songs to playlists
- Remove songs from playlists
- Prevent duplicate songs
- View total playlists and songs
- Responsive design for mobile devices
- Logout functionality

## Technologies Used

### Frontend

- JavaScript
- React
- Vite
- React Router
- CSS
- iTunes Search API

### Backend

- Node.js
- Express
- MongoDB
- Mongoose
- JSON Web Tokens
- bcryptjs

## Deployment

The frontend is deployed using Netlify.

The backend is deployed using Render.

The database is hosted using MongoDB Atlas.

## API

PlaylistHub uses the iTunes Search API to search for music.

The API provides:

- Song title
- Artist name
- Album name
- Album artwork
- 30-second audio previews
